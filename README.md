# 🎓 Placementor — AI-Powered Placement Assistant

## 📌 Brief Description
Placementor is an AI-powered web application designed to help students 
prepare for campus placements. It analyzes resumes, provides ATS scores, 
generates personalized improvement suggestions using LLMs, and helps 
discover job opportunities.

---

## 🛠️ Technology Stack and Tools Used

| Layer | Technology |
|---|---|
| Backend | Python, FastAPI |
| Frontend | React.js, HTML, CSS |
| AI/ML | LLM (Large Language Model), PDF Parser |
| Database | SQLite |
| Authentication | Google OAuth |
| Others | Git, GitHub, VS Code |

---

## ✨ Features and Functionalities Implemented

- 📄 **Resume Analysis** — Upload PDF resume and get detailed feedback
- 📊 **ATS Score** — Get ATS compatibility score with improvement tips
- 🤖 **AI Suggestions** — Personalized resume improvement using LLM
- 💼 **Job Discovery** — Scrape job listings with location-based filtering
- 📝 **Resume Templates** — Access multiple professional resume templates
- ✅ **GitHub Validation** — Validate and evaluate GitHub profile
- 📈 **Activity Dashboard** — Track user activity and progress
- 🔐 **Google Authentication** — Secure login via Google OAuth

## ⚙️ Installation and Execution Steps

### Prerequisites
- Python 3.8+
- Node.js
- Git

### Backend Setup
```bash
# Clone the repository
git clone https://github.com/Mehta-prog/placement-assistant.git
cd placement-assistant

# Install Python dependencies
pip install -r requirements.txt

# Run the backend server
python main.py
```

### Frontend Setup
```bash
# Navigate to frontend folder
cd frontend

# Open index.html in browser
# OR for React frontend
cd frontend-react
npm install
npm start
```

### Access the Application
Open your browser and go to `http://localhost:8000`
